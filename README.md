## 📖 About

Voidbane is a cooperative horror demo built in Unity. You can play solo or with up to 4 players online. The game currently features 2 complete levels and a third one in development.

The project was built entirely from scratch: gameplay programming in C#, original 3D models made in Blender, and textures created with Substance Painter. Multiplayer was implemented using Netcode for GameObjects.

---

## ✨ Features

- 🧟 1–4 player online co-op via server-based networking
- 🗺️ 2 complete levels + 1 in development
- 🎨 Original 3D models and textures
- 🔦 First-person perspective with atmospheric horror setting
